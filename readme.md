# Sanskar Kushwah Portfolio

A responsive personal portfolio website built with HTML and CSS. The website presents my education, experience, projects, technical skills, certificates, and contact details in a clean single-page layout.

## Preview

Open `index.html` in any modern browser to view the portfolio locally.

## Features

- Responsive single-page portfolio design
- Sticky navigation bar
- Hero section with profile summary
- Education and internship timeline
- Projects section with GitHub links
- Skills and tools section
- Certificates and achievements section
- Contact section with email, phone, LinkedIn, and GitHub links
- Download CV button

## Tech Stack

- HTML5
- CSS3
